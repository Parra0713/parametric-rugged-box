# logs/

Registros de las pruebas de barrido (`npm run test:sweep`):

- `sweep-<fecha>.log` — detalle por caso: registro interno del motor (tiempos,
  mecánica elegida, voladizos y soportes), avisos y cada comprobación ✔/✘.
- `sweep-latest.json` — resumen del último barrido.

Desde la interfaz, la tarjeta **Registro** muestra lo mismo para el diseño
actual y permite descargarlo (adjúntalo al reportar un fallo).
